# Bandidos y agente aleatorio

Este laboratorio utiliza el entorno `.venv` y el `requirements.txt` de la raíz del repositorio.

Desde esta carpeta, después de preparar el entorno compartido:

```sh
source ../.venv/bin/activate
python -m jupyterlab
```

Selecciona **Python (reinforcement-learning)**. Consulta el [README general](../README.md) para preparar el entorno, trabajar en Windows o añadir dependencias. La preparación del entorno no completa los ejercicios pendientes.
