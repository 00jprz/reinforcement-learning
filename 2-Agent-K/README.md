# Agent K

Este laboratorio utiliza el entorno `.venv` y el `requirements.txt` de la raíz del repositorio.

Desde esta carpeta, después de preparar el entorno compartido:

```sh
source ../.venv/bin/activate
python -m jupyterlab
```

Selecciona **Python (reinforcement-learning)**. Añade las nuevas dependencias al archivo de la raíz. Consulta el [README general](../README.md) para preparar el entorno o trabajar en Windows.
